# Transica

**Get into ChatGPT and Claude, and stay there.**

Transica runs the whole lifecycle of your MCP app:

- **Build** it from your API. You approve every tool.
- **Secure** it with the sign-in your customers already use, and per-tool access: public tools stay open, the rest ask for sign-in.
- **List** it in ChatGPT's and Claude's directories, checked against each one's rules.
- **Keep it working** after listing: daily rule checks, health checks, tool-change diffs and alerts.

## Free, no account

- [AI-readiness scan](https://transica.dev): can AI agents read and use your page?
- [MCP directory check](https://transica.dev/tools/mcp-directory-check): does your MCP server meet ChatGPT's and Claude's rules?
- Transica's own MCP server: `https://transica-mcp.transica.dev/mcp` (no sign-in; official MCP Registry: `dev.transica/transica`)
